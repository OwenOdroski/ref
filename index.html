Disclaimers

All information in this tool is derived from public sources. The sources are listed below. The information included may be incorrect because it is either from released tech data from F-16A/B variants, outdated TOs approved for public release, or public sources with little to no credibility.

WUC search, Reference Designator search, and the cockpit layout diagram are based off block 50/52 F-16s or older. Many systems have advanced since this public data has been released. All information must be verified, especially anything related to avionics.

SECURITY

This system uses a built in API called Web Crypto AES (Advanced Encryption Standard). It is considered secure but technically not required for use of this platform. This program does not connect to the internet, or have any access to the internet. It relys on the phones security. The reason Web Crypto AES is used is for potential controlled distribution of this contents of this program.

The data in the file contains all of the information (listed below), except for fuel load calculator, oil consumption calculator, and torque converter.

The encrypted file is embedded with user identifiable information. The creator of the encrypted file is responsible for this information being accurate. This is used in case of distribution of the encrypted file, the person responsible can be held accountable.

No data is ever stored in a readable format. JSON (JavaScript Object Notation) is what is saved behind the encrypted file. The data is saved between uses using IndexedDB. This is open and readable in a normal website but in this case it's an encrypted string. The decryption key is only saved as a local variable and gets wiped every time the app closes.

Within the metadata is an expiration date. The file will expire, then wipe itself from the device. The user will still have the .ENC file, but will be unable to decrypt it.

Since this program does not connect to the internet and is not managed by any third-party servers, encrypted data can not be intercepted. The only way an unauthorized user can gain access to the data is by brute forcing the password. The requirements for the username and password must combine to be at least 16 bytes (or 16 characters but differs on certain variables). To brute force this setup, it would take over 1,000 times as long as our universe has existed (about 13.8 billion years)

Torque converter

This does not change the torque applied to the fastener. When using an inline extension, torque wrench settings must be adjusted to prevent over- or under-tightening of a fastener, using standard torque compensation formulas. Always verify torque procedures with applicable Technical Orders. The formula and explantion are below.

The torque equation is as follows:

Tapplied = Tsetting × ( (L + E × cos(A)) / L )

Where:
Tsetting = Setting on torque wrench
Tapplied = Desired torque at fastener
L = Length of torque wrench (center of handle to drive)
E = Length of extension (center of drive to fastener)
A = Angle of extension (0deg being directly outward)

Units are irrelevant because this formula scales Tapplied
